# Flutter Compiler Plugin Changelog

- Removed deprecated `acode.addCommand` usage.
- Reworked menu/UI rendering for plugin commands.
- Added Help & Support, Docs, Donate, and Social menus.
- Added Changelog menu (this file).
- Improved error handling for Termux and Flutter install.
- Improved settings dialog for debug mode.
